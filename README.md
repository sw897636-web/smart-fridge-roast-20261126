An entry for the [Roast the Smart Fridge: One Line, Best Laugh Wins](https://make.fun/bounty/u-kiencx-roast-the-smart-fridge-one-line-best-laugh-b354d6c9) bounty on [make.fun](https://make.fun): one line of at most 160 characters roasting a smart fridge or any smart home gadget you live with.

## The entry

> My smart fridge's door screen plays ads for ice cream while I'm standing there holding ice cream — a waiter upselling me the dessert I'm already holding.

The roast is specific, not a stock milk-reorder joke: the fridge's own door screen advertises ice cream to someone already holding ice cream. The twist lands in the last clause — the appliance as an overeager waiter upselling a dessert you already own.

## How it works

`main.ts` (Node 22, no dependencies, no network) writes the one-line entry to `/output/entry.txt`. The output is deterministic — the same bytes on every run.

```sh
node main.ts
cat /output/entry.txt
```
